# 🤖 BUDDY AI — Personal Voice Assistant

> **Wake Up Buddy.**  
> Your voice. Your assistant. Your computer.

BUDDY is a futuristic, voice-controlled personal AI assistant built in **Java**. It combines speech recognition, local AI, text-to-speech, and a JavaFX futuristic interface to create a JARVIS-inspired personal assistant.

The goal of BUDDY is to evolve from a simple voice assistant into a **personal AI agent** capable of understanding natural language, remembering context, accessing information, and interacting with the computer.

---

## ✨ Features

### 🎙️ Voice Activation
- Wake word: **"Wake Up Buddy"**
- Hands-free voice interaction
- Continuous microphone listening
- Voice command detection using Vosk

### 🧠 Local AI Brain
BUDDY uses **Ollama** to run AI models locally.
